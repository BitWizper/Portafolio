PROYECTO ESCOLAR / 01 · 2024–2026

Proyecto Danhee.

Plataforma web que conecta a clientes con reposteros para personalizar productos y servicios. Esta ficha reúne la información disponible hasta el momento; los detalles del proyecto se ampliarán más adelante.

Una conexión hecha a tu gusto.

Danhee acerca a quienes buscan un postre personalizado con reposteros que pueden prepararlo. Incluye consultas sobre pasteles, precios y disponibilidad para orientar a los clientes durante la elección.

Personalización de productos

Conecta a los clientes con reposteros para personalizar productos y servicios.

Asistente con IA

Ayuda a resolver consultas de pasteles, precios y disponibilidad.

Productos en 3D

Modelos tridimensionales permiten visualizar los productos desde el frontend.

Gestión de imágenes

Cloudinary se integra para la gestión de los archivos e imágenes del proyecto.

Backend y datos

El backend está desarrollado con Node.js y Express; Sequelize trabaja con MySQL.

Despliegue

El proyecto incluye el despliegue del frontend mediante GitHub Pages.
